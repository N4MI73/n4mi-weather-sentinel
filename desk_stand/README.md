# Weather Sentinel Desktop Stand

A one-piece, 3D-printable desktop stand for a Weather Sentinel built with an **M5Stack CoreS3 SE and attached M5GO-BOTTOM 3**.

The stand holds the display at a **27° rearward tilt from vertical** (63° above the desk). Two small front tabs retain the device, while open triangular support frames leave the side LEDs, ports, and buttons exposed. A rear brace joins the frames, and an opening through the base reduces material use.

Designed with ChatGPT, with physical print testing and refinement for the Weather Sentinel project.

## Files and versions

| File | Description |
|---|---|
| `CoreS3_Stand_V1.stl` | Original stand with a 76 × 84 mm footprint |
| `CoreS3_Stand_V1.scad` | Editable, parametric source for V1 |
| `CoreS3_Stand_V2.stl` | Compact stand with a 64 × 70 mm footprint |
| `CoreS3_Stand_V2.scad` | Editable, parametric source for V2 |

V2 removes 6 mm from each side of the base and 14 mm from the rear, reducing desk area by approximately **30%**. It preserves V1's cradle, retaining tabs, support frames, rear brace, and viewing angle. Both stands are approximately **45.4 mm tall**, excluding the device.

## Device fit

The design uses an assembled device size of approximately **54 × 54 × 23 mm**. The cradle depth is **24 mm**, providing 1 mm of total thickness clearance. This is a gravity cradle rather than a snap-fit enclosure; there are no side clamps.

The assembled thickness was measured directly rather than calculated by adding the two modules' published dimensions. Measure your own assembly if its configuration differs.

The two retaining tabs are each 7 mm wide and extend 4 mm along the device face. Bottom microSD access is not preserved. Check access with your actual cables and hardware, particularly if using a different module stack.

## Printing

Import the STL in **millimeters**. It is already oriented with the flat base on the build plate.

| Setting | Starting point |
|---|---|
| Material | PLA or PETG |
| Layer height | 0.20 mm |
| Walls | 3–4 |
| Infill | 15–20%, gyroid |
| Supports | Off; inspect the sliced bridge paths |
| Orientation | Flat base down |

Use the correct printer and material profiles in your slicer. The project owner's printer is a **Bambu Lab X2D**.

The rear brace spans a **29 mm bridge**. The stand is intended to print without supports, but bridge quality depends on material and print settings. Use your slicer's normal bridge settings and check its layer preview before printing. Print time and filament use should come from your own slice.

V1 was printed in PLA and reported to fit well and function well. V2 was successfully sliced in Bambu Studio and selected for a PETG test print; physical results have not yet been recorded in this README.

## Optional rubber feet

The supplied STLs have flat undersides. Adhesive rubber pads can be applied directly to help resist sliding during touchscreen use.

To add recesses, set `rubber_feet = true` in the OpenSCAD source and export a new STL. The default recesses are **8 mm in diameter and 1 mm deep**. Approximately 2 mm thick adhesive feet will protrude below the base.

## Customizing the model

Open the `.scad` file in [OpenSCAD](https://openscad.org/), edit the parameters near the top, render with **F6**, and export an STL.

| Parameter | Default | Purpose |
|---|---:|---|
| `device_width` | 54 mm | Nominal device width for preview and checks |
| `device_height` | 54 mm | Nominal device height for preview |
| `device_thickness` | 23 mm | Assembled device thickness |
| `thickness_clearance` | 1 mm | Total extra cradle depth, not clearance per side |
| `view_angle` | 27° | Rearward tilt from vertical |
| `base_width` | 76 / 64 mm | V1 / V2 base width |
| `base_depth` | 84 / 70 mm | V1 / V2 base depth |
| `rail_width` | 7 mm | Width of each support frame and tab |
| `rail_spacing` | 36 mm | Distance between support centers |
| `support_height` | 42 mm | Rear support height along the device |
| `tab_height` | 4 mm | Retaining height along the device face |
| `rubber_feet` | `false` | Enable underside recesses |

Set `show_device = true` to display a translucent nominal device in the preview. It is excluded from the exported STL.

Changing the width or height parameters alone does not automatically resize every stand feature. Adjust the base, rail spacing, and support height as appropriate. After any change, render the model and inspect fit, structural connections, overhangs, and bridges in the slicer.

## Validation and test fitting

Both supplied STLs were checked for watertightness, consistent face orientation, positive volume, and a single connected component. V1 was also checked for interference against the nominal device shape. V2 was generated by trimming only the base of the verified V1 mesh, leaving the device-contact geometry intact.

The OpenSCAD sources describe the corresponding geometry, but compilation of those source files was not verified during generation. The STLs were generated and checked separately.

After printing, confirm that the device sits on both bottom rails, rests against the rear supports, and is retained by both tabs. Check LEDs, buttons, and connected cables. Test for sliding or tipping during gentle taps around the screen, with the cable attached. V2's smaller footprint provides less tipping margin than V1.
